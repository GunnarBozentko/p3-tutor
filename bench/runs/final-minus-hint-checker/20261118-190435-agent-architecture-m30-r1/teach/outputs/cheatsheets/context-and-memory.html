Formulas

  • Total input over n calls: n·a + d·n(n − 1)/2 (a = first call's input, d = tokens added per step). Example: 5 × 2,200 + 1,000 × 10 = 21,000.
  • Cost = tokens × price per token. Example: 21,000 × $3 / 1,000,000 = $0.063 (illustrative price).
  • Cosine similarity = dot product / (length of u × length of v). Example: (4,3) and (3,4) give 24 / 25 = 0.96.

Reminders

  • The model keeps nothing between calls; the program resends the list.
  • Clearing old tool results and compaction shrink the list but lose detail.
  • A note or a student's claim never decides a safety question; an unreadable record means "not permitted yet".
