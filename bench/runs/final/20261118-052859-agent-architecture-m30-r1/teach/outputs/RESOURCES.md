# Agent Architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, structured note-taking, sub-agents, just-in-time retrieval. Use for: deciding what stays in context, what is saved, and how the agent finds information.
- [Documentation: "Context windows" (Anthropic)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how history accumulates across turns, context editing and compaction. Use for: window sizes, what is billed, and the tools for managing context.
- [Article: "LLM Powered Autonomous Agents" by Lilian Weng](https://lilianweng.github.io/posts/2023-06-23-agent/)
  Survey of agent components including short-term and long-term memory with an external vector store. Use for: the wider picture of agent memory and retrieval.
