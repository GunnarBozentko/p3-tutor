Context and memory in an agent

Where information lives

InformationPlace
Instructions, tool descriptionsContext, every call
This run's historyContext; trim by clearing, compaction, sub-agent
Per-student preferencesNotes saved by the program, loaded at session start
Long manualsChunked store; retrieve the top k
Training status, bookingsOfficial record, read by a tool at decision time

Formulas

  • Total input over n calls: n·S + g·n(n−1)/2. Example: S = 2,050, g = 1,600, n = 4 gives 17,800 tokens.
  • Cosine similarity: u·v / (|u||v|). Example: (3,4) and (6,8) give 1.
  • Recall = relevant retrieved / all relevant. Precision = relevant retrieved / all retrieved.

Rules

  • The model keeps no state between calls; the program resends the history.
  • The window is a ceiling; the bill follows the tokens sent.
  • A note or a claim never grants a risky permission; read the record through a tool.
