Context and memory in an agent

Where information lives

PlaceHoldsRule
Context windowInstructions, tool definitions, messages, tool results, outputThe program resends all of it at every call; you pay for it each time
Saved notesWhat only the student can tell youShort, pruned, put back at session start; never decide a risky permission
Records and manualsTraining status, calendar, machine manualsRead through a tool when needed; retrieve manual pages, never carry a whole manual

Formulas

  • Call n carries base + a1 + ... + a(n-1) input tokens.
  • Total over N calls = N·base + Σ (N − k)·ak.
  • Precision = relevant retrieved / retrieved. Recall = relevant retrieved / all relevant.
  • Rough token rule: 100 tokens is about 75 words.

Ways to cut context

  • Make tools return less (arguments such as machine and date).
  • Clear re-fetchable tool results; leave a stub.
  • Compact a long conversation, and say what the summary must keep.

Safety rule

A risky permission is decided by the authoritative record, read through a tool at that moment. A claim or a saved note never decides it. If the record cannot be read: not permitted yet, and name staff who can confirm.
