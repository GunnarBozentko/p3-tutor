# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context, context rot, just-in-time retrieval, compaction, note-taking, sub-agents. Use for: anything on what an agent keeps in context and how to manage it.
- [Docs: "Context windows" (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how history accumulates, what happens at the limit. Use for: exact behavior of the window and token counting.
- [Docs: "Pricing" (Claude Platform Docs)](https://platform.claude.com/docs/en/about-claude/pricing)
  Per-million-token input and output rates, caching and batch modifiers. Use for: budget calculations; check current rates before quoting.
- [Paper: "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks" by Lewis et al. (NeurIPS 2020)](https://papers.nips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html)
  The paper that introduced retrieval-augmented generation. Use for: the origin and idea of retrieval as memory.
