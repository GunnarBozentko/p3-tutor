Context and memory in an agent

One-page reference from the lesson on context and memory.

Where information lives

KindLivesUse for
ContextOne call, resent each stepPrompt, messages, tool results needed now
NotesAcross sessions, outside the modelShort preferences, open tasks, pointers
Retrieval storePermanent, outside the modelLong manuals, fetched as chunks

Formulas, with numbers

  • Input at call k: about S + (k-1)d. Total over n calls: nS + d·n(n-1)/2. With S = 2,100 and d = 700: n = 10 gives 52,500; n = 20 gives 175,000.
  • Cost: input tokens × input price + output tokens × output price. Example at $1 and $5 per million: 8,850 in and 500 out is about 1.1 cents.
  • Cosine similarity: dot product / (length × length). Example: (3, 4) and (5, 12) give 63 / 65 = 0.97.

Rules

  • The model keeps nothing between calls; the program resends what it wants seen.
  • Clear stale tool results; compact long chats; use sub-agents for focused side tasks.
  • A note or a student's claim never decides a safety permission. Read the training record by tool at the moment of the decision; if it cannot be read, answer "not permitted yet" and point to staff.
