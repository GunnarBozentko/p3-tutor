# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a finite resource, context rot, tool-result clearing, compaction, structured note-taking, just-in-time retrieval and sub-agents. Use for: what to keep in context, what to save, how to retrieve.
- [Docs: "Context windows" (Claude Platform documentation)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how history accumulates across turns, window sizes, the overflow error. Use for: token and cost accounting, definitions.
- [Article: "Building effective agents" (Anthropic Engineering)](https://anthropic.com/engineering/building-effective-agents)
  The augmented model (retrieval, tools, memory), workflows versus agents, and the advice to use the simplest design that works. Use for: architecture choices; its tooling notes are dated (a note on the page says so).
