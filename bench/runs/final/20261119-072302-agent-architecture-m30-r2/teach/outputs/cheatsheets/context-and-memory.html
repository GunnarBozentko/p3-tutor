Context and memory in an agent

Summary of the lesson on context and memory. The model sees only the text in the current call.

Cost rules

  • Input of call k+1 = input of call k + the model's request + the tool result.
  • n calls with first input I and equal growth a cost nI + a·n(n−1)/2.
  • A result added after call j is resent on calls j+1 to n: cost a(n−j).
  • Example: 1,550 + 1,910 + 3,970 + 4,130 = 11,560 input tokens; clearing a 2,000-token result before call 4 gives 9,560.

Housekeeping

  • Tool result clearing: drop bulky tool results the model has used.
  • Compaction: summarize the history and continue from the summary; tune for recall first.
  • Cosine similarity: cos θ = a·b / (|a||b|); a = (1, 2), b = (2, 1) gives 0.8.

Sources: Anthropic, Effective context engineering for AI agents; Claude context windows.
