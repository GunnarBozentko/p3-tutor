Variance of an average of B trees

Var(average) = ρσ² + ((1 − ρ)/B) σ²

  • σ²: variance of one tree's prediction at a point. ρ: pairwise correlation of two trees' predictions. B: number of trees.
  • Floor: ρσ². More trees remove only the second term.
  • ρ = 0 gives σ²/B. ρ = 1 gives σ², no gain.
  • Example: σ² = 100, ρ = 0.3, B = 10 gives 30 + 7 = 37.

Bias-variance

Expected squared error = bias² + variance + irreducible noise. Averaging keeps bias about the same (small rise), and cuts variance.

What lowers ρ

  • Bootstrap samples for each tree.
  • A random subset of features at each split (max_features below 1.0 in scikit-learn).
