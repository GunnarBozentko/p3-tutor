Formulas

  • Input billed = sum of every call's input. With overhead F and s tokens added per step, m calls cost about m*F + s*m(m+1)/2. Example: F=2,000, s=500: 3 calls = 9,000; 10 calls = 47,500.
  • Cosine similarity = (q . c) / (|q| |c|). Example: q=(1,0), c=(0.9,0.1): 0.9/0.906 = 0.994.

Rules

  • The model keeps nothing between calls; your program owns memory.
  • A big window is a budget, not a goal: recall degrades and cost grows with length.
  • Retrieval ranks by similarity; it does not verify that a chunk applies.
