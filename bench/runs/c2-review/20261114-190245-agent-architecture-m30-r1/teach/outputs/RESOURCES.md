# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context rot, just-in-time retrieval, compaction, note-taking and sub-agents. Use for: what to keep in context and how to manage long runs.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, window sizes, errors at the limit, compaction and context editing. Use for: token budgeting and limits.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file-based memory across sessions, its commands and the path-safety warning. Use for: saving information between visits.
