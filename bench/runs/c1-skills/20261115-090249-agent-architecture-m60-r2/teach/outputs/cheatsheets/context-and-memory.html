Context and memory: cheat sheet

From lesson 1.

Terms

  • Context window: all the text the model can read on one call.
  • Token: a chunk of text; the unit of window size and of billing.
  • Session: one conversation; its message list is discarded at the end.
  • Compaction: replacing history with a summary (lossy).
  • RAG: retrieve chunks, put them in the window with the question.

Rules

  • The model keeps nothing; the program resends the message list each call.
  • Input on call n = fixed part + question + everything added in steps 1 to n-1.
  • Cut cost: fewer steps, smaller tool results, clear used results.
  • Between sessions: save then load. Safety facts come from a system of record via a tool.
  • Cosine similarity = (u · v) / (|u| |v|). Keyword search for exact strings, embeddings for paraphrase.
