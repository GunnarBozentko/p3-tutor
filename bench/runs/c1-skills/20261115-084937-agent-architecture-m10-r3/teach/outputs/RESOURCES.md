# Agent architecture Resources

## Knowledge

- [Anthropic: Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Anthropic's engineering post on context as a finite attention budget, just-in-time retrieval, compaction and note-taking. Use for: what to keep in context, memory, retrieval.
- [Claude docs: Understanding the context window](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official documentation on context window size and behavior. Use for: limits and pricing details; check the current page, as figures change by model.
- [Liu et al., "Lost in the Middle: How Language Models Use Long Contexts"](https://Huggingface.co/papers/2307.03172)
  TACL 2024 paper showing models use the start and end of long inputs better than the middle. Use for: arguing for short, well-placed context.
