Context and memory: where does each fact go?

PlaceLivesUse for
Context (messages list)One session; re-sent every callThe current question, tool results
Saved notesAcross sessions; load what is neededSoft facts: preferences, past topics
Program-owned recordAcross sessions; staff-controlledFacts that gate safety, such as training
Retrieval indexPermanent; search per questionLong manuals

Rules

  • The model keeps nothing between calls; your program re-sends the context.
  • Cost per call grows with context size; recall can worsen as it fills (context rot).
  • Shrink with clearing old tool results or compaction; summaries delete what they omit.
  • Knowledge base under about 200,000 tokens: consider putting it all in the prompt.
  • Keyword search for exact codes; embedding search for meaning; hybrid if both matter.

Source: Anthropic, Effective context engineering; Contextual Retrieval. Lesson: 0001.
