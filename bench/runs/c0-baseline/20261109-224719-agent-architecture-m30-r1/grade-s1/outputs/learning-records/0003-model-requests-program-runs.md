# Open misconceptions: the model runs tools itself (M4) and remembers across sessions (M3)

On quiz 0001 (s1), Riley understood the loop, the need for a stopping condition and that tools are chosen from descriptions. But Riley believed the model opens the booking system and runs the tools itself inside one call (q2, q4), and that it remembers earlier sessions on its own (q6).
Lessons on context and memory should first make clear that each model call sees only what the program puts in its input.

**Evidence:** quiz 0001, submission s1, items q2, q4, q6 (q1 and q3 correct).

**Implications:** Rebuild the "who acts" picture (model writes a request, program runs the tool, result goes into the next call) before teaching memory. Submission s2, taken four days later, is not yet graded and will show whether this has changed.
