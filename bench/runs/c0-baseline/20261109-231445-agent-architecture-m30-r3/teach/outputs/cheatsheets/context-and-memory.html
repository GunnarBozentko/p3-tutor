Rules

  • The model keeps nothing between calls; the program resends the context.
  • Input cost = sum of every call's whole input, so a token kept for n more calls is paid n more times.
  • Keep the smallest set of useful tokens: short tool results, clear used results, compact near the limit.
  • Reading a note or passage does not teach the model; the text must be loaded each time.
  • Tag every chunk with its machine and section.
