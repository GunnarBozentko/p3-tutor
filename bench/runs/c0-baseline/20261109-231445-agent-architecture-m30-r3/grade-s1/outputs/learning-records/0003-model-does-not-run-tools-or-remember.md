# Open misconceptions: the model runs the tools (M4), and remembers by itself (M3)

On quiz 0001 (submission s1), Riley understood the loop and how tools are chosen from descriptions, but wrote that the model "runs the 3 tools itself" in one call (M4) and that it "remembers on its own" past tool choices across sessions (M3).
Future lessons should separate what the model outputs (text: a tool request or an answer) from what the program does (runs tools, stores and re-sends information), before building context and memory on top.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6. Items q1 and q3 were correct.

**Implications:** Memory lessons must show that nothing persists between sessions unless the program saves it and puts it back into the input. Check M4 again with spaced practice (submission s2 is ungraded).
